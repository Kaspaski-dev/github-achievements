# GitHub Achievements

Repositorio de práctica para desbloquear logros de GitHub en la cuenta **Kaspaski-dev**.

## Estado

| Logro | Estado | Cómo |
|---|---|---|
| Pair Extraordinaire | x4 (oro) | Commits con co-autor en PRs fusionados |
| Pull Shark | x3 (128 PRs) | PRs fusionados |
| Quickdraw | En curso | Cerrar una issue o PR en menos de 5 minutos |
| YOLO | Pendiente | Fusionar un PR con revisión solicitada sin esperar la revisión (necesita un colaborador) |
| Galaxy Brain | Pendiente | Respuestas aceptadas en GitHub Discussions de otros repos |
| Starstruck | Pendiente | 16 estrellas reales en un repo |
| Public Sponsor | Pendiente | Patrocinar a alguien con GitHub Sponsors |
